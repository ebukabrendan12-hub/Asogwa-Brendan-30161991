# Portfolio 4: NoSQL and Advanced Data Models
Student: Asogwa Brendan (30161991)
Case Study: Clinic Management System

This portfolio applies the same clinic case study using four different NoSQL data models.

Models used:

Document model (MongoDB): clinicEvents collection for flexible visit notes
Key-Value model (Redis): fast patient cache
Column model (Cassandra): scalable patient records
Graph model (Neo4j): patient-visited-doctor relationships
